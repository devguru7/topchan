# Topchan Ops — Автопилот ресепшн для Topchan Hostel (Ташкент)

**Topchan Ops** — единая операционная система ресепшн, Telegram Mini App консоль, мост Bnovo / E-mehmon и 6-карманная мультивалютная касса для **Topchan Hostel (Ташкент, Узбекистан)**.

---

## Ключевые модули

- **Шахматка («Карточки сегодня» + «Шахматка 14 дней»)**: 15 физических комнат (Small, Yellow, Blue, Green, Mix Dorm 6 коек, Female Dorm 6 коек), горизонтальный 14-дневный Gantt-календарь, движок защиты от овербукинга с мгновенным подбором альтернативных свободных комнат.
- **Смена и Zero-Typing автопилот**: живое время **Ташкент (`Asia/Tashkent`, UTC+5)**, голосовая диктовка `ru-RU` (Web Speech API) + серверный **Gemini AI** разбор команд с 100% детерминированным офлайн-парсером, чек-лист смены и автоматический расчёт турсбора РУз (БРВ 440 000 сум, порог 10 комнат, льгота детям до 16 лет).
- **6-карманная касса + Дебаггер расхождений + Z-отчёт**: два курса (`Acc` проживание ↑ 1 000 / `Ex` сдача ↓ 1 000) на базе живого курса ЦБ РУз (`/api/rates/cbu`, кэш 1 час), купюрный пересчёт, автоматический разбор последних 5 кассовых операций при расхождении, печать Акта передачи смены (`@media print`) и 3 встроенных SVG-графика аналитики.
- **Паспортный MRZ OCR (только в оперативной памяти)** и **E-mehmon**: загрузка фото паспорта в `CheckInModal` для извлечения 2-строчного TD3 MRZ через Gemini Vision (снимки не сохраняются на диск), либо мгновенный офлайн-парсинг MRZ.
- **Сервисы, Горничные, Гостевой QR-консьерж и Review Booster**: изолированные таймеры стиральной машины (`22 мин / $2`, `55 мин / $3`), 2-этапная приёмка уборки, камера хранения `#B01+`, трансферы в аэропорт (3 км / `$5`), автономный мобильный QR-консьерж (`?mode=guest&room=Small-1`, RU/EN/UZ/ZH), печать ламинированных QR-постеров комнат и 2-ступенчатый Review Booster.
- **Telegram-бот, AI-черновики ответов и экспорт**: генерация мультиязычных ответов гостям (RU/EN/UZ/ZH), планировщик напоминаний по времени Ташкента (`08:00`, `10:00`, `11:30`, `12:00`, `13:00`, `14:00`, `23:30`), аудит-лог, выгрузка CSV / JSON.

## Быстрый старт (локально)

```bash
npm install
cp .env.example .env
npm run dev
```

Приложение и API-сервер Express запускаются вместе на **`http://localhost:3000`**.

### Проверка сборки и тестов

```bash
npm run check
# Выполняет последовательно: tsc --noEmit && npm test && vite build
```

### Продакшн-запуск

```bash
npm run build
npm start
```

## Настройка переменных окружения (`.env`)

| Переменная | Обязательно | Назначение |
| --- | --- | --- |
| `PORT` | Нет (по умолч. `3000`) | Порт Express-сервера |
| `APP_URL` | Нет | Публичный адрес для QR-ссылок |
| `GEMINI_API_KEY` | Нет | Серверный ключ Gemini AI (парсер команд, MRZ OCR, черновики ответов). Без ключа работает локальный движок |
| `BNOVO_ACCOUNT_ID`, `BNOVO_API_KEY` | Нет | Интеграция с Bnovo API v1 («Старт») |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | Нет | Отправка сменных напоминаний в Telegram по времени Ташкента |
| `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` | Нет | Облачная синхронизация Supabase (без них используется офлайн-режим LocalStorage) |

## Подключение Supabase (PostgreSQL + RLS)

1. Создайте проект в [Supabase](https://supabase.com) и откройте **SQL Editor**.
2. Выполните содержимое файла `supabase/schema.sql` — будут созданы все 18 операционных таблиц, таблица `property_snapshots`, индексы по `property_id` и политики Row-Level Security (RLS).
3. Укажите `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` в `.env` и перезапустите приложение. Индикатор в разделе **Настройки** переключится на `Supabase Cloud`.

## Активация Bnovo API v1 («Старт»)

1. Войдите в личный кабинет **Bnovo PMS**.
2. Откройте **Меню → Bnovo Octopus → API-доступ** и включите тариф **API «Старт»**.
3. Скопируйте **Account ID** и **API-ключ** в переменные `BNOVO_ACCOUNT_ID` и `BNOVO_API_KEY` в `.env`.
4. Серверный клиент (`server/bnovo.ts`) автоматически кэширует JWT-токен на 23 часа, обновляет его при `401` и выполняет backoff при `429`. Проверка: `GET /api/bnovo/bookings`.

## Установка Chrome-расширения (Мост Bnovo ↔ E-mehmon)

В репозитории находится готовое расширение **Manifest V3** в папке `chrome-extension/`:

1. Откройте в Google Chrome страницу **`chrome://extensions`**.
2. Включите **«Режим разработчика»** (правый верхний угол).
3. Нажмите **«Загрузить распакованное расширение»** и выберите папку `chrome-extension/`.
4. Закрепите иконку **Topchan Ops** на панели инструментов — клик открывает боковую панель (Chrome Side Panel):
   - На вкладке `*.bnovo.ru` нажмите **«1. Считать бронь из Bnovo»**.
   - Перейдите на форму регистрации гостя в `*.emehmon.uz` и нажмите **«2. Заполнить E-mehmon в 1 клик»**.
